# ADR-011: Служебные эндпоинты для гейтвея

**Статус:** предложен

## Контекст

Гейтвей опрашивает `/jwks` и `/rules` без аутентификации. Они не должны смешиваться с
административным API: правило роли `admin` (`* /admin/**`) не должно случайно открывать или
менять то, что читает гейтвей.

## Решение

- `/jwks` отдаёт только публичные ключи, то есть публичную информацию. Путь `/jwks`
  (стандартный `/.well-known/jwks.json` возможен как алиас), без аутентификации и без
  `@RequireAdmin`. Добавлять путь в `public` гейтвея необязательно.
- `/rules` внутренний: не входит в `/admin/**`, не покрыт правилами ни одной роли, не
  указан в `public`. Доступен только из внутренней сети, где его читает гейтвей напрямую.
  Управление правилами идёт через отдельные административные пути (`/admin/rules`).
- URL обоих эндпоинтов в конфиге гейтвея должны совпадать с путями сервиса.

## Последствия

- Нельзя открыть `/rules` наружу ошибкой в правиле роли.
- Изменение пути это изменение конфига гейтвея, и делается оно осознанно.
- Аутентификация `/rules` (статический токен, mTLS) возможна позже и потребует правки
  гейтвея.
